# The tests' clip

`librispeech.wav` is three utterances of LibriSpeech's test-clean set (speaker 237, chapter 126133, utterances 0002–0004), joined with a pause of 1.2 s before, between and after them, as a writer dictating pauses. 16 kHz mono, 16-bit. `librispeech.json` says where each starts and ends, and what was said.

LibriSpeech is by Vassil Panayotov, Guoguo Chen, Daniel Povey and Sanjeev Khudanpur ("LibriSpeech: an ASR corpus based on public domain audio books", ICASSP 2015), from LibriVox's public-domain recordings, and is licensed under CC BY 4.0: https://www.openslr.org/12/.
